01

¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje de marcado estándar para crear páginas web. No es un lenguaje de programación, sino un lenguaje que describe la estructura y el contenido de una página mediante etiquetas.

Cada página web que ves en tu navegador está construida, en su base, sobre HTML. CSS le da estilos y JavaScript le añade interactividad, pero HTML es el esqueleto.

💡 Analogía Piensa en HTML como los cimientos y paredes de una casa. CSS sería la pintura y decoración, y JavaScript sería la electricidad e instalaciones.

¿Qué puede hacer HTML?

  • Estructurar texto en párrafos, títulos, listas
  • Insertar imágenes, videos y audio
  • Crear formularios para recopilar datos
  • Establecer enlaces entre páginas
  • Definir la semántica del contenido (qué es cada cosa)
  • Incrustar contenido externo (mapas, iframes)

Un archivo HTML es simplemente un archivo de texto con extensión .html. El navegador lo interpreta (parsea) y construye el DOM (Document Object Model), una representación en árbol del documento.

        │   ├── h1
        │   └── p
        └── footer

04

Estructura básica de un documento HTML

Todo archivo HTML debe tener esta estructura mínima:

<!DOCTYPE html>
<html lang="es">

  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera página</title>
  </head>

  <body>
    <h1>¡Hola Mundo!</h1>
    <p>Mi primera página web.</p>
  </body>

</html>
⚠️ Importante Esta estructura es OBLIGATORIA. Sin ella, los navegadores intentan "adivinar" cómo renderizar la página, lo que puede causar comportamientos inesperados.
05

La etiqueta <head>

El <head> contiene metadatos (información sobre el documento, no visible en la página). El navegador y los motores de búsqueda la usan para configurar y entender la página.

EtiquetaPara qué sirve¿Obligatoria?

<meta viewport>Controla el zoom en dispositivos móviles✅ Sí (responsive)
<title>Título de la pestaña del navegador y SEO✅ Sí
<meta name="description">Descripción para buscadores (SEO)Recomendada
<link rel="stylesheet">Vincula archivo CSS externoNo
<link rel="icon">Favicon de la páginaNo
<script>JavaScript (preferible al final del body)No
<style>CSS internoNo
 
<head>
  <!-- Codificación: SIEMPRE primero -->
  <meta charset="UTF-8">

  <!-- Responsivo -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- SEO -->
  <meta name="description" content="Descripción corta de la página (máx 160 chars)">
  <meta name="author" content="Tu Nombre">

  <!-- Título -->
  <title>Título de la página | Sitio Web</title>

  <!-- CSS externo -->
  <link rel="stylesheet" href="estilos.css">

  <!-- Favicon -->
  <link rel="icon" href="favicon.ico">
</head>
06

La etiqueta <body>

El <body> contiene todo el contenido visible de la página: texto, imágenes, botones, formularios, etc. Es donde pasas la mayor parte del tiempo en HTML.

💡 Regla de oro Los scripts <script src="..."> deben colocarse justo antes del </body> para no bloquear la carga del contenido visible. 
<body>

  <!-- Todo el contenido visible va aquí -->
  <header>...</header>
  <main>...</main>
  <footer>...</footer>

  <!-- Scripts al final -->
  <script src="app.js"></script>
</body>
07

DOCTYPE

La declaración <!DOCTYPE html> no es una etiqueta HTML, es una instrucción al navegador sobre qué versión de HTML usar. Siempre va en la primera línea.

<!-- HTML5 (el que debes usar siempre) -->
<!DOCTYPE html>

<!-- HTML 4.01 (obsoleto) -->
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN"
  "http://www.w3.org/TR/html4/strict.dtd">
⚠️ Sin DOCTYPE El navegador entra en "quirks mode" (modo antiguo) y renderiza la página como si fuera HTML antiguo, causando bugs visuales impredecibles.

Etiquetas Semánticas HTML5

Las etiquetas semánticas describen el significado del contenido, no solo su apariencia. Mejoran SEO, accesibilidad y mantenimiento.

📌 ¿Por qué semántica? Un lector de pantalla puede navegar por los landmarks semánticos. Google entiende mejor la estructura de tu contenido. Tú mismo entiendes el código más fácilmente.
<header>
Cabecera
Encabezado de página o sección. Logo, nav principal.
<nav>
Navegación
Conjunto de enlaces de navegación principales.
<main>
Contenido principal
El contenido único de la página. Solo uno por doc.
<article>
Artículo
Contenido independiente: post, noticia, comentario.
<section>
Sección
Grupo temático con encabezado propio.
<aside>
Contenido lateral
Sidebar, anuncios, contenido relacionado.
<footer>
Pie de página
Copyright, links legales, contacto, redes sociales.
<figure>
Figura
Imagen, diagrama o código con leyenda.
<figcaption>
Leyenda
Pie de imagen dentro de <figure>.
<time>
Fecha/Hora
Fecha legible por máquinas con datetime="".
<address>
Dirección
Información de contacto del autor/organización.
<details>
Desplegable
Contenido expandible/colapsable nativo.
<article>
  <header>
    <h2>Título del artículo</h2>
    <time datetime="2025-04-11">11 de abril de 2025</time>
  </header>

  <section>
    <h3>Introducción</h3>
    <p>Contenido del artículo...</p>
  </section>

  <figure>
    <img src="foto.jpg" alt="Descripción">
    <figcaption>Foto del autor en el evento</figcaption>
  </figure>

  <footer>
    <address>Por <a href="mailto:autor@email.com">Juan García</a></address>
  </footer>
</article>

<!-- Details/Summary (acordeón nativo) -->
<details>
  <summary>¿Qué es HTML? (clic para expandir)</summary>
  <p>HTML es el lenguaje de marcado estándar...</p>
</details>

Principios de Maquetación HTML

La maquetación (layout) define cómo se organiza visualmente el contenido. En HTML, la estructura semántica sienta las bases; CSS Flexbox y Grid hacen la disposición visual.

Elementos bloque vs. elementos inline

Bloque (Block)Inline
Ocupa todo el ancho disponibleSolo ocupa su propio ancho
Siempre empieza en nueva líneaFluye dentro del texto
div, p, h1-h6, section, article, ul, ol, table, form...span, a, strong, em, img, input, button...

Estructura típica de una página

<!DOCTYPE html>
<html lang="es">
<head>...</head>
<body>

  <!-- 1. CABECERA -->
  <header>
    <a href="/"><img src="logo.svg" alt="Logo"></a>
    <nav>
      <ul>
        <li><a href="/">Inicio</a></li>
        <li><a href="/sobre">Sobre mí</a></li>
        <li><a href="/contacto">Contacto</a></li>
      </ul>
    </nav>
  </header>

  <!-- 2. HERO (sección destacada) -->
  <section class="hero">
    <h1>Título principal de la página</h1>
    <p>Subtítulo o descripción breve</p>
    <a href="#inicio" class="cta">Comenzar</a>
  </section>

  <!-- 3. CONTENIDO PRINCIPAL + SIDEBAR -->
  <main>
    <div class="layout">

      <article>
        <h2>Artículo principal</h2>
        <p>Contenido...</p>
      </article>

      <aside>
        <h2>Contenido relacionado</h2>
        <ul>...</ul>
      </aside>

    </div>
  </main>

  <!-- 4. PIE DE PÁGINA -->
  <footer>
    <p>&copy; 2025 Mi Sitio. Todos los derechos reservados.</p>
    <nav aria-label="Footer">
      <a href="/privacidad">Privacidad</a>
      <a href="/terminos">Términos</a>
    </nav>
  </footer>

</body>
</html>

Buenas prácticas

✅ Hacer siempre

  • Usar etiquetas semánticas en lugar de <div> cuando sea posible
  • Incluir alt en todas las imágenes
  • Vincular cada <input> con su <label>
  • Validar el HTML en validator.w3.org
  • Usar lang en el <html>
  • Incluir meta viewport para diseño responsivo
  • Indentar el código para mayor legibilidad
  • Usar comillas en los valores de atributos
  • Escribir etiquetas en minúscula
  • Cerrar todas las etiquetas

❌ Evitar

  • Usar <table> para maquetación visual
  • Usar estilos inline (style="") para todo
  • Usar <b> e <i> cuando debería ser <strong> y <em>
  • Usar más de un <h1> por página
  • Saltarse niveles de encabezado (ir de h1 a h4 sin h2 y h3)
  • Usar <br> para crear espacios (usa CSS margin/padding)
  • Poner scripts en el <head> sin defer
  • Imágenes sin alt
  • Formularios sin label
<!-- ❌ MAL: sin semántica -->
<div class="header">
  <div class="nav"><a href="/">Inicio</a></div>
</div>

<!-- ✅ BIEN: semántico -->
<header>
  <nav><a href="/">Inicio</a></nav>
</header>

<!-- ❌ MAL: imagen sin alt -->
<img src="producto.jpg">

<!-- ✅ BIEN: con alt descriptivo -->
<img src="producto.jpg" alt="Camiseta azul talla M">

Accesibilidad (a11y)

La accesibilidad web permite que personas con discapacidades puedan usar tu sitio. Las normas WCAG son el estándar internacional.

Atributos ARIA esenciales

AtributoPara qué sirve
aria-labelEtiqueta para lectores de pantalla
aria-labelledbyReferencia a otro elemento como etiqueta
aria-describedbyDescripción adicional para lectores de pantalla
aria-hidden="true"Oculta el elemento de lectores de pantalla
aria-expandedEstado expandido/colapsado (menú, acordeón)
aria-liveAnuncia cambios dinámicos en la página
