01

¿Qué es CSS?

CSS (Cascading Style Sheets, u hojas de estilo en cascada) es el lenguaje que controla la apariencia visual de los documentos HTML. Si HTML define la estructura y el contenido, CSS define cómo se ve: colores, tipografía, espaciado, posición de los elementos, animaciones y mucho más.

La palabra cascada hace referencia a cómo se aplican las reglas: cuando varias reglas afectan al mismo elemento, un sistema de prioridad (especificidad) determina cuál prevalece.

TecnologíaResponsabilidadEjemplo
HTMLEstructura y contenidoUn párrafo, un botón, una imagen
CSSPresentación visualColor del texto, tamaño, márgenes
JavaScriptComportamiento e interacciónAnimaciones dinámicas, formularios
Concepto clave

CSS separa el contenido de la presentación. Esto permite cambiar el diseño completo de un sitio sin tocar el HTML, y reutilizar los mismos estilos en múltiples páginas.

02

Sintaxis y estructura

Una regla CSS se compone de un selector (a qué elemento aplica) y un bloque de declaraciones (qué aspecto cambia). Cada declaración tiene una propiedad y un valor, separados por : y terminados en ;.

h1 {
  color: #1D9E75;
  font-size: 2rem;
  font-weight: 600;
  /* Esto es un comentario */
}
CSS

SelectorElige el elemento al que se aplicah1, .clase, #id
PropiedadEl aspecto visual que se modificacolor, margin, font-size
ValorLo que se asigna a la propiedadred, 16px, bold
DeclaraciónEl par propiedad + valorcolor: red;
Regla CSSSelector + bloque completoEl bloque de arriba completo
Comentarios

Los comentarios se escriben entre /* */ y son ignorados por el navegador. Úsalos para documentar secciones y propiedades no evidentes.

03

Formas de incluir CSS en HTML

Existen tres formas de vincular estilos CSS a un documento HTML. Cada una tiene su caso de uso.

1. Hoja externa — recomendado
<link rel="stylesheet"
      href="estilos.css">
2. Estilo interno — por página
<style>
  h1 { color: teal; }
</style>
3. Estilo en línea — solo casos puntuales
<h1 style="color: teal; font-size: 2rem;">Hola</h1>
MétodoVentajaDesventajaPrioridad
Hoja externaReutilizable, cacheable, organizadoRequiere archivo extraNormal
Estilo internoTodo en un archivoNo reutilizable entre páginasNormal + anula externa
Estilo en líneaPrioridad alta, rápido para pruebasDifícil de mantener, no reutilizableMuy alta
Buena práctica

En proyectos reales, usa siempre hojas externas. El navegador las almacena en caché, lo que mejora la velocidad de carga de páginas sucesivas.

04

Selectores principales

Los selectores determinan a qué elementos HTML se aplican los estilos. Dominar los selectores es fundamental para escribir CSS preciso y eficiente.

p { }
Selector de tipo. Aplica a todos los <p> del documento
.clase { }
Selector de clase. Reutilizable en múltiples elementos
#id { }
Selector de ID. Único por página, alta especificidad
* { }
Selector universal. Aplica a todos los elementos
div p { }
Descendiente. Todos los <p> dentro de un <div>
div > p { }
Hijo directo. Solo <p> inmediatamente dentro del <div>
h1 + p { }
Hermano adyacente. El <p> que sigue inmediatamente a <h1>
h1 ~ p { }
Hermanos siguientes. Todos los <p> que siguen a <h1>
a:hover { }
Pseudoclase. Estado al pasar el cursor
a:focus { }
Pseudoclase. Elemento con foco del teclado
li:nth-child(2) { }
Pseudoclase estructural. El segundo hijo
p::first-line { }
Pseudoelemento. Primera línea de un párrafo
p::before { }
Pseudoelemento. Inserta contenido antes del elemento
h1, h2, h3 { }
Selector múltiple. Agrupa elementos con mismos estilos
[type="text"] { }
Selector de atributo. Por valor del atributo HTML
[class^="btn"] { }
Atributo que empieza con "btn"
/* Ejemplos combinados */

}

button:hover {            /* botón al pasar el cursor */
  background: #0F6E56;
  cursor: pointer;
}

input[required] {         /* inputs obligatorios */
  border: 2px solid #E24B4A;
}

li:nth-child(odd) {       /* filas impares de una lista */
  background: #f5f5f5;

05

Especificidad y cascada

Cuando varias reglas CSS afectan al mismo elemento, el navegador decide cuál aplica según la especificidad. Cada tipo de selector tiene un peso diferente.

Estilos en línea style="…" 1,0,0,0
IDs #mi-id 0,1,0,0
Clases, atributos, pseudoclases .clase / [attr] / :hover 0,0,1,0
Tipos y pseudoelementos p / h1 / ::before 0,0,0,1
Universal * 0,0,0,0 
/* Especificidad: 0,0,0,1 — tipo */
p { color: gray; }

/* Especificidad: 0,0,1,1 — clase + tipo → gana */
.texto p { color: blue; }

/* Especificidad: 0,1,0,0 — ID → gana sobre lo anterior */
#contenido { color: green; }

/* !important: anula todo (usar solo en casos extremos) */
p { color: red !important; }
CSS
Evitar

El uso excesivo de !important indica problemas de arquitectura CSS. Si te ves forzado a usarlo frecuentemente, revisa la estructura de tus selectores.

07

El modelo de caja (Box Model)

Todo elemento HTML es una caja rectangular. El box model define las cuatro capas que la componen, de adentro hacia afuera: contenido → padding → borde → margen.

contenido
width × height
margin
border
padding
contenido
.elemento {
  /* Tamaño del contenido */
  width: 300px;
  height: 150px;

  /* Padding: espacio entre contenido y borde */
  padding: 20px;

  /* Borde visible */
  border: 2px solid #1D9E75;

  /* Margen: espacio externo respecto a otros elementos */
  margin: 16px;

  /* border-box: width incluye padding y border */
  box-sizing: border-box;
}

/* Aplicar border-box globalmente — mejor práctica */
*, *::before, *::after {
  box-sizing: border-box;
}
CSS
Por qué usar border-box

Con box-sizing: border-box, si defines width: 300px con padding: 20px, el ancho total sigue siendo 300px. Sin él, el ancho total sería 340px (300 + 20 + 20). El primero es mucho más predecible.

08

Flexbox

Flexbox (Flexible Box Layout) es un modelo de diseño unidimensional: organiza elementos en una sola fila o columna. Es ideal para distribuir espacio, alinear elementos y construir navbars, barras de herramientas y grupos de tarjetas.

.contenedor {
  display: flex;
  flex-direction: row;          /* row | column | row-reverse | column-reverse */
  justify-content: center;     /* alineación en eje principal */
  align-items: center;         /* alineación en eje secundario */
  gap: 16px;                    /* espacio entre hijos */
  flex-wrap: wrap;              /* permite salto de línea */
}

09

CSS Grid

CSS Grid es un sistema de layout bidimensional: organiza elementos en filas y columnas simultáneamente. Es perfecto para estructuras de página completas, galerías de imágenes y layouts asimétricos complejos.

/* Layout clásico: sidebar + contenido */
.pagina {
  display: grid;
  grid-template-columns: 280px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
  gap: 24px;
}

/* Galería responsiva sin media queries */
.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 20px;
}

/* Elemento que ocupa varias columnas */
.encabezado {
  grid-column: 1 / -1;   /* de inicio hasta el final */
}

/* Nombrar áreas para mayor claridad */
.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 250px 1fr;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main   { grid-area: main; }
.footer { grid-area: footer; }

Flexbox vs Grid

Usa Flexbox para distribuir elementos en una dirección (fila o columna). Usa Grid cuando necesites controlar filas y columnas simultáneamente, o para el layout general de la página. Pueden combinarse: Grid para el layout exterior, Flexbox dentro de cada componente.

Variables CSS (Custom Properties)

Las variables CSS permiten definir valores reutilizables en un solo lugar. Si cambias el valor de una variable, se actualiza en todos los lugares donde se usa. Son esenciales para mantener consistencia y simplificar el mantenimiento.

/* Definición: generalmente en :root para scope global */
:root {
  /* Colores */
  --color-primario:   #1D9E75;
  --color-secundario: #185FA5;
  --color-texto:      #222222;
  --color-fondo:      #F8F7F2;
  --color-borde:      #DEDDD6;

  /* Tipografía */
  --fuente:         'Inter', sans-serif;
  --fuente-mono:    'JetBrains Mono', monospace;
  --texto-base:     16px;
  --texto-sm:       14px;
  --texto-lg:       18px;

  /* Espaciados */
  --espacio-xs: 4px;
  --espacio-sm: 8px;
  --espacio-md: 16px;
  --espacio-lg: 32px;
  --espacio-xl: 64px;

  /* Bordes y sombras */
  --radio:       8px;
  --radio-lg:    16px;
  --sombra:      0 2px 8px rgba(0,0,0,.08);
  --transicion:  all 0.2s ease;
}

/* Uso con var() */
.boton {
  background: var(--color-primario);
  font-family: var(--fuente);
  padding: var(--espacio-sm) var(--espacio-md);
  border-radius: var(--radio);
  transition: var(--transicion);
}

/* Variables en scope local (solo para ese componente) */
.alerta {
  --alerta-color: #E24B4A;
  border-left: 4px solid var(--alerta-color);
  color: var(--alerta-color);
}

/* Modo oscuro con variables */
@media (prefers-color-scheme: dark) {
  :root {
    --color-texto: #F0EFE9;
    --color-fondo: #1A1A18;
    --color-borde: #3A3A38;
  }
}

Animaciones y transiciones

CSS permite crear animaciones sin JavaScript. Hay dos herramientas principales: transitions (para cambios de estado) y animations con @keyframes (para secuencias complejas).

Transition — cambios de estado suaves

.boton {
  background: #1D9E75;
  transform: translateY(0);
  box-shadow: 0 2px 8px rgba(0,0,0,.1);

  /* propiedad | duración | función de tiempo | retardo */
  transition: background .2s ease,
               transform  .2s ease,
               box-shadow .2s ease;
}

.boton:hover {
  background: #0F6E56;
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgba(29,158,117,.35);
}

/* Funciones de tiempo */
/* ease (default) | linear | ease-in | ease-out | ease-in-out */
/* cubic-bezier(0.4, 0, 0.2, 1)  — Material Design */
CSS

@keyframes — animaciones complejas

/* Definir la animación */
@keyframes pulsar {
  0%    { transform: scale(1);    opacity: 1; }
  50%   { transform: scale(1.15); opacity: .75; }
  100%  { transform: scale(1);    opacity: 1; }
}

@keyframes girar {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

@keyframes entrar-desde-abajo {
  from { transform: translateY(30px); opacity: 0; }
  to   { transform: translateY(0);    opacity: 1; }
}

/* Aplicar la animación */
.notificacion {
  /* nombre | duración | función | retardo | iteraciones | dirección | fill-mode */
  animation: pulsar 2s ease-in-out infinite;
}

.spinner {
  animation: girar 1s linear infinite;
}

.tarjeta {
  animation: entrar-desde-abajo 0.4s ease-out 0.1s both;
  /* "both": aplica el estado inicial antes de empezar */
}

/* Respetar preferencias del usuario */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}

Para animaciones fluidas, anima solo transform y opacity. Estas propiedades las gestiona la GPU y no provocan reflow. Evita animar width, height, top, left o margin en bucles.

Media Queries y diseño Responsive

Las media queries permiten aplicar estilos distintos según las características del dispositivo o ventana del navegador: ancho, orientación, resolución, preferencia de color, etc. Son la base del diseño responsive.

Breakpoints comunes

NombreRango típicoMedia QueryDispositivo
Mobile< 640px@media (max-width: 639px)Teléfonos
Tablet640px – 1024px@media (min-width: 640px)Tablets, landscape
Desktop1024px – 1280px@media (min-width: 1024px)Laptops
Wide> 1280px@media (min-width: 1280px)Monitores grandes
/* ——————————————————————————————————————
   ENFOQUE MOBILE-FIRST (recomendado):
   Empieza con móvil, añade complejidad para pantallas más grandes
   —————————————————————————————————————— */

/* Estilos base — MÓVIL */
.contenedor {
  padding: 16px;
  max-width: 100%;
}

.galeria {
  display: grid;
  grid-template-columns: 1fr;     /* 1 columna en móvil */
  gap: 16px;
}

/* Tablet (640px y arriba) */
@media (min-width: 640px) {
  .contenedor { padding: 24px; }
  .galeria     { grid-template-columns: repeat(2, 1fr); }
}

/* Desktop (1024px y arriba) */
@media (min-width: 1024px) {
  .contenedor { max-width: 1200px; margin: 0 auto; padding: 40px; }
  .galeria     { grid-template-columns: repeat(3, 1fr); }
}

/* ——————————————————————————————————————
   OTRAS MEDIA QUERIES ÚTILES
   —————————————————————————————————————— */

/* Orientación */
@media (orientation: landscape) { ... }
@media (orientation: portrait)  { ... }

/* Pantallas de alta resolución (Retina) */
@media (-webkit-min-device-pixel-ratio: 2), (min-resolution: 192dpi) {
  /* Usar imágenes 2x */
}

/* Preferencia de modo oscuro */
@media (prefers-color-scheme: dark) {
  :root { --color-fondo: #1A1A18; --color-texto: #F0EFE9; }
}

/* Preferencia de movimiento reducido */
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}

/* Impresión */
@media print {
  .sidebar, .nav, .ads { display: none; }
  body { font-size: 12pt; color: black; }
}

Empieza siempre con los estilos para móvil y usa min-width para escalar hacia arriba. Es más fácil añadir que quitar, y Google prioriza el índice mobile-first.

Buenas prácticas

✓ Correcto
/* Clases descriptivas por función */
.btn-primario { }
.tarjeta-producto { }
.seccion-hero { }

/* Propiedades ordenadas */
.elemento {
  /* 1. Layout */
  display: flex;
  position: relative;
  /* 2. Box model */
  width: 100%;
  padding: 16px;
  /* 3. Visual */
  background: white;
  border-radius: 8px;
  /* 4. Tipografía */
  font-size: 1rem;
}
✗ Evitar
/* Nombres sin significado */
.rojo { }
.div1 { }
.estiloNuevo { }

/* !important en exceso */
.btn {
  color: red !important;
  font-size: 14px !important;
}

/* Números mágicos sin contexto */
.elemento {
  margin-top: 37px;
  left: 143px;
}
  • Usa variables CSS --nombre para colores, fuentes, espaciados y sombras reutilizables
  • Declara * { box-sizing: border-box; } al inicio de cada proyecto
  • Nombra clases por función (.btn-primario), no por apariencia (.btn-verde). Si el color cambia, el nombre sigue siendo válido
  • Organiza tu CSS: reset → variables → tipografía → layout → componentes → utilidades → media queries
  • Diseña mobile-first: estilos base para móvil, luego min-width para escalas mayores
  • Para animaciones performantes, usa solo transform y opacity en bucles
  • Respeta la accesibilidad: usa :focus-visible, asegura contraste 4.5:1 mínimo, no elimines el outline sin reemplazarlo
  • Incluye @media (prefers-reduced-motion: reduce) para respetar a usuarios con sensibilidad al movimiento
  • Usa metodologías de nomenclatura como BEM (.bloque__elemento--modificador) en proyectos grandes

/* BEM: Bloque__Elemento--Modificador */

/* Bloque */

.tarjeta__precio  { color: #1D9E75; font-weight: 700; }

/* Modificadores del bloque */
.tarjeta--destacada { border: 2px solid #1D9E75; }
.tarjeta--horizontal {
  display: flex;
  flex-direction: row;

¿Cuándo y para qué usar CSS?

CSS es indispensable en cualquier proyecto web. Estos son sus casos de uso más importantes:

🎨
Identidad visual
Colores, tipografía y estilos de marca consistentes en todo el sitio
📐
Maquetación
Estructura de páginas con Flexbox y Grid para cualquier diseño
📱
Diseño responsive
Adaptar el diseño a móvil, tablet y escritorio con media queries
✨
Animaciones
Transiciones, efectos hover y animaciones @keyframes sin JS
🌙
Modo oscuro
Con variables CSS y prefers-color-scheme, sin JavaScript
♿
Accesibilidad
Contraste, estados de foco, tamaños legibles y motion reducido
⚡
Rendimiento
GPU animations con transform/opacity, lazy loading de fuentes
🖨️
Impresión
Hojas de estilo para impresión con @media print
Flujo de trabajo recomendado

HTML semántico → CSS reset + variables globales → tipografía base → layout con Grid → componentes con Flexbox → estados interactivos → animaciones → media queries. Esta secuencia genera código mantenible, escalable y performante.
