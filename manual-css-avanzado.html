01

Custom Properties (Variables CSS)

Las Custom Properties —coloquialmente "variables CSS"— son propiedades definidas por el desarrollador que almacenan valores reutilizables. A diferencia de los preprocesadores, son dinámicas: se pueden cambiar en tiempo de ejecución con JavaScript, respetan el scope del DOM y participan en la herencia.

CSS
/* ——— Definición y uso básico ——— */
:root {
  --color-primario: #1A6B3C;
  --radio: 8px;
  --espacio: 1rem;
  --fuente-display: 'Playfair Display', serif;
  --sombra: 0 4px 14px rgba(0,0,0,.1);
}

.tarjeta {
  background: var(--color-primario);
  border-radius: var(--radio);
  padding: var(--espacio);
  /* Fallback si la variable no existe */
  color: var(--color-texto, black);
}

/* ——— Scope local ——— */
.alerta-roja {
  --color-primario: #DC2626; /* sobreescribe solo aquí */
  background: var(--color-primario);
}

/* ——— Variables en cálculos ——— */
:root {
  --base: 4px;
  --espacio-sm: calc(var(--base) * 2);  /* 8px  */
  --espacio-md: calc(var(--base) * 4);  /* 16px */
  --espacio-lg: calc(var(--base) * 8);  /* 32px */
}

/* ——— Variables para temas (dark mode) ——— */
:root {
  --bg: white;
  --texto: #1C2B1A;
  --superficie: #F7F3EA;
}

[data-theme="dark"] {
  --bg: #111D12;
  --texto: #E8F5EB;
  --superficie: #1C2B1D;
}

/* ——— Variables en inline styles (JS) ——— */
/* elemento.style.setProperty('--mi-var', valor) */
/* getComputedStyle(elem).getPropertyValue('--mi-var') */

/* ——— Variables en @keyframes ——— */
:root { --delay: 0s; }
.item-1 { --delay: 0.1s; }
.item-2 { --delay: 0.2s; }

.item {
  animation: fadeIn 0.4s var(--delay) both;
}

Diferencia con variables de preprocesadores

Las variables de Sass ($var) se resuelven en compilación y no existen en el navegador. Las Custom Properties de CSS existen en el DOM, son heredables, cambiables con JS y pueden responder a media queries.

02

@layer — Cascade Layers

Las Cascade Layers (CSS 2022) permiten organizar los estilos en capas con prioridad explícita, eliminando los conflictos de especificidad. Los estilos en una capa posterior tienen mayor prioridad, sin importar la especificidad de los selectores dentro de ella.

reset Normalize / reset CSS base Prioridad 1 (menor)
base Tipografía, colores, variables globales Prioridad 2
layout Grid, Flexbox, containers Prioridad 3
components Botones, tarjetas, modales Prioridad 4
utilities Clases de utilidad (.hidden, .flex…) Prioridad 5
sin @layer Estilos fuera de cualquier capa Prioridad 6 (mayor)
CSS
/* ——— Declarar el orden de capas ——— */
@layer reset, base, layout, components, utilities;

/* ——— Añadir estilos a cada capa ——— */
@layer reset {
  *, *::before, *::after { box-sizing: border-box; }
  body { margin: 0; }
}

@layer base {
  :root {
    --color-primario: #1A6B3C;
    --fuente: 'Source Serif 4', serif;
  }
  body { font-family: var(--fuente); }
}

@layer components {
  .btn {
    background: var(--color-primario);
    color: white;
    padding: 8px 16px;
    border-radius: 6px;
  }
}

@layer utilities {
  .hidden { display: none; }
  .flex   { display: flex; }
  .w-full { width: 100%; }
}

/* ——— Capas anidadas ——— */
@layer components {
  @layer base     { .btn { ... } }
  @layer variants { .btn-primary { ... } }
  @layer states   { .btn:hover { ... } }
}

/* ——— Importar archivo con su capa ——— */
@import "reset.css" layer(reset);
@import "bootstrap.css" layer(libs);
/* Bootstrap queda contenida — nunca gana a tu código */
✓ Con @layer (predecible)
/* Aunque .btn#especial tiene
   más especificidad que .btn,
   utilities está DESPUÉS de
   components → utilities gana */
@layer components {
  .btn#especial { color: red; }
}
@layer utilities {
  .override { color: blue; }
}
/* .btn#especial.override → azul */
✗ Sin @layer (guerra de especificidad)
/* Hay que usar !important
   o añadir selectores más
   específicos para ganar */
.btn#especial { color: red; }

.override {
  color: blue !important;
  /* O: .btn.override { ... } */
}

@scope y @starting-style

@scope — Estilos con contexto

@scope permite aplicar estilos solo dentro de un componente específico, evitando fugas de estilos y la necesidad de convenciones como BEM para el scoping.

CSS
/* @scope: estilos dentro de .tarjeta */
@scope (.tarjeta) {
  :scope { border: 1px solid #ddd; } /* .tarjeta misma */
  h2    { font-size: 1.25rem; }     /* solo h2 dentro de .tarjeta */
  p     { color: #555; }
}

/* Con límite inferior — no afecta dentro de .widget */
@scope (.card) to (.widget) {
  p { color: blue; }
  /* Aplica a 
 dentro de .card PERO NO dentro de .widget */
}

/* ——— @starting-style ——— */
/* Define el estado inicial ANTES de que un elemento aparezca.
   Permite animar elementos que se añaden al DOM con display:none */

.modal {
  opacity: 1;
  transform: scale(1);
  transition: opacity .3s, transform .3s;
}

@starting-style {
  .modal {
    opacity: 0;
    transform: scale(0.9);
  }
  /* Al aparecer en el DOM, el modal anima desde estos valores */
}

/* Animar entry/exit con popover API */
[popover] {
  opacity: 1;
  transition: opacity .2s, display .2s allow-discrete;
}

[popover]:not(:popover-open) {
  opacity: 0;
}

@starting-style {
  [popover]:popover-open { opacity: 0; }
}

Pseudo-elementos avanzados

Los pseudo-elementos permiten generar contenido visual y aplicar estilos a partes específicas de un elemento sin añadir HTML extra. Son fundamentales para decoraciones, overlays y efectos creativos.

CSS
/* ——— ::before y ::after ——— */
.tarjeta {
  position: relative;
  overflow: hidden;
}

/* Overlay de gradiente */
.tarjeta::before {
  content: '';                         /* OBLIGATORIO */
  position: absolute;
  inset: 0;
  background: linear-gradient(
    to bottom, transparent 50%, rgba(0,0,0,.7)
  );
  pointer-events: none;
}

/* Contador con ::before */
ol { counter-reset: items; }
li { counter-increment: items; position: relative; padding-left: 2rem; }
li::before {
  content: counter(items);
  position: absolute; left: 0;
  background: var(--emerald);
  color: white;
  width: 1.5rem; height: 1.5rem;
  border-radius: 50%;
  display: grid; place-items: center;
  font-size: .8rem; font-weight: 600;
}

/* ——— ::first-line y ::first-letter ——— */
article p:first-of-type::first-letter {
  font-size: 3em;
  font-family: 'Playfair Display', serif;
  float: left;
  line-height: 1;
  margin-right: .1em;
  color: var(--emerald);
}

/* ——— ::selection ——— */
::selection {
  background: #C8E6D4;
  color: #0F4526;
}

/* ——— ::marker (listas) ——— */
li::marker {
  content: '✦ ';
  color: var(--emerald);
  font-size: .7em;
}

/* ——— ::placeholder ——— */
input::placeholder {
  color: #9B7B2A;
  font-style: italic;
  opacity: .6;
}

/* ——— ::backdrop (dialog / fullscreen) ——— */
dialog::backdrop {
  background: rgba(28,43,26,.6);
  backdrop-filter: blur(6px);
}

/* ——— ::file-selector-button ——— */
input[type="file"]::file-selector-button {
  background: var(--emerald);
  color: white;
  border: none;
  padding: 6px 14px;
  border-radius: 6px;
  cursor: pointer;
  margin-right: 12px;
}

Selectores avanzados

CSS
/* ——— :is() — grupo con especificidad alta ——— */
:is(h1, h2, h3, h4) { line-height: 1.2; }

/* ——— :where() — igual pero especificidad = 0 ——— */
:where(h1, h2, h3) { margin-bottom: .75em; }
/* Útil para resets: fácil de sobreescribir */

/* ——— :has() — selector de padre ——— */
.card:has(img)          { display: grid; grid-template-columns: 120px 1fr; }
.card:has(> p:last-child){ padding-bottom: 2rem; }
form:has(:invalid)       { border: 2px solid red; }
label:has(+ input:required)::after { content: ' *'; color: red; }

/* ——— :not() avanzado ——— */
p:not(.intro, .nota, .legal) { text-indent: 1.5em; }
a:not([href])                { opacity: .4; cursor: default; }

/* ——— :nth-child() con pattern ——— */
li:nth-child(3n + 1)  { color: red; }    /* 1, 4, 7, 10... */
li:nth-child(-n + 3)  { font-weight: 700; } /* primeros 3 */
li:nth-last-child(2)  { color: blue; }   /* penúltimo */

/* ——— :nth-child() con selector (CSS 4) ——— */
li:nth-child(2 of .destacado) {
  /* 2do li que tenga clase .destacado */
  font-size: 1.2rem;
}

/* ——— :focus-visible ——— */
button:focus-visible {
  outline: 3px solid var(--emerald);
  outline-offset: 3px;
}
button:focus:not(:focus-visible) { outline: none; }
/* Muestra foco solo con teclado, no con ratón */

/* ——— :popover-open, :modal, :fullscreen ——— */
[popover]:popover-open { background: white; }
dialog:modal           { border-radius: 12px; }
video:fullscreen        { object-fit: cover; }

/* ——— Selector de atributos avanzado ——— */
a[href^="https"]    { } /* empieza con */
a[href$=".pdf"]     { } /* termina con */
a[href*="ejemplo"]  { } /* contiene */
a[lang|="es"]       { } /* es "es" o empieza con "es-" */
[data-size~="lg"]   { } /* contiene la palabra "lg" */

/* ——— color-mix() — mezclar colores ——— */
.btn-hover {
  background: color-mix(in srgb, #1A6B3C 80%, white);
  /* 80% verde + 20% blanco */

.overlay {
  background: color-mix(in hsl, var(--color), transparent 40%);

.display-p3 {
  color: color(display-p3 0.1 0.8 0.4);
  /* P3 tiene 25% más colores que sRGB */

.degradado-suave {
  background: linear-gradient(in oklch,
    oklch(55% 0.18 145),   /* verde esmeralda */
    oklch(70% 0.14 220)    /* azul claro */
  );
  /* OKLCH evita el "gris muerto" en mitad del gradiente */
}

/* ——— round(), mod(), rem() ——— */
.snap {
  width: round(327px, 10px);  /* → 330px (redondea a múltiplo de 10) */
}

/* ——— sin() y cos() — geometría ——— */
.item-circular {
  --i: 0;
  --total: 8;
  --radio: 120px;
  --angulo: calc(360deg / var(--total) * var(--i));
  transform:
    translateX(calc(cos(var(--angulo)) * var(--radio)))
    translateY(calc(sin(var(--angulo)) * var(--radio)));
}

/* ——— env() — variables del entorno ——— */
.safe-area {
  padding:
    env(safe-area-inset-top)
    env(safe-area-inset-right)
    env(safe-area-inset-bottom)
    env(safe-area-inset-left);
  /* iPhone: respeta el notch y home indicator */
}

Filtros y efectos visuales

CSS
/* ——— filter: aplicado al elemento ——— */
.imagen {
  filter:
    blur(0)
    brightness(1)          /* 0=negro, 1=normal, 2=doble brillo */
    contrast(1)             /* 0=gris, 1=normal */
    grayscale(0)            /* 0=color, 1=bn */
    hue-rotate(0deg)       /* gira la rueda de color */
    invert(0)               /* 0=normal, 1=negativo */
    opacity(1)              /* igual que la propiedad opacity */
    saturate(1)             /* 0=gris, 1=normal, 2=saturado */
    sepia(0)                /* 0=normal, 1=sepia completo */
    drop-shadow(4px 4px 8px rgba(0,0,0,.3));
  /* drop-shadow sigue el contorno real (PNG, SVG) */
}

/* ——— backdrop-filter ——— */
.glass-card {
  background: rgba(255,255,255,.15);
  backdrop-filter:
    blur(12px)
    saturate(1.8);
  -webkit-backdrop-filter: blur(12px) saturate(1.8);
  border: 1px solid rgba(255,255,255,.25);
}

/* ——— mix-blend-mode ——— */
.texto-blend {
  mix-blend-mode: multiply;  /* multiply|screen|overlay|difference|etc */
}

.imagen::after {
  mix-blend-mode: color;  /* tinta de color sobre B&W */
}

/* ——— isolation (contexto de blend) ——— */
.no-blend { isolation: isolate; }
/* Crea un stacking context que bloquea el blend */

/* Casos de uso de filtros */
.foto-retro       { filter: sepia(.4) contrast(1.1) brightness(.95); }
.foto-duotono     { filter: grayscale(1); mix-blend-mode: multiply; }

Scroll-driven Animations

Las Scroll-driven Animations (Chrome 115+, Firefox 110+) permiten controlar el progreso de una animación usando el scroll del usuario, completamente en CSS — sin JavaScript, sin IntersectionObserver, sin requestAnimationFrame.

CSS
/* ——— scroll() — progreso de la página ——— */

/* Barra de progreso de lectura */
.barra-progreso {
  position: fixed;
  top: 0; left: 0;
  width: 100%; height: 3px;
  background: var(--emerald);
  transform-origin: left;
  animation: progreso linear;
  animation-timeline: scroll(root block);
}

@keyframes progreso {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}

/* ——— view() — progreso del elemento en pantalla ——— */

/* Parallax con scroll */
.parallax-img {
  animation: parallax linear;
  animation-timeline: view();
}

@keyframes parallax {
  from { transform: translateY(-30px); }
  to   { transform: translateY(30px); }
}

/* Revelar al entrar en pantalla */
.revelar {
  animation: revelar linear both;
  animation-timeline: view();
  animation-range: entry 0% entry 30%;
  /* Anima mientras el elemento entra en viewport */
}

@keyframes revelar {
  from { opacity: 0; transform: translateY(40px); }
  to   { opacity: 1; transform: translateY(0); }
}

/* ——— Rangos de animación ——— */
/* entry:        cuando el elemento entra al viewport */
/* exit:         cuando sale del viewport */
/* contain:      mientras está completamente en pantalla */
/* cover:        mientras cubre alguna parte del scroll port */
/* entry 0%:     cuando el borde inferior toca el fondo */
/* entry 100%:   cuando el borde superior llega al fondo */

/* ——— Named scroll timeline ——— */
.contenedor-scroll {
  overflow-y: scroll;
  scroll-timeline-name: --mi-scroll;
  scroll-timeline-axis: block;
}

.animado {
  animation-timeline: --mi-scroll;
  animation: mi-animacion linear;
}
Soporte en 2024

Scroll-driven Animations tienen soporte en Chrome 115+, Edge 115+ y Firefox 110+. Safari lo implementó en versión 18.2 (2024). Usa @supports (animation-timeline: scroll()) para detección de características.

Subgrid

Subgrid permite que un elemento hijo participe en el grid de su padre, compartiendo las pistas (columnas o filas) en lugar de crear una grid nueva. Resuelve el problema de alineación de columnas internas entre tarjetas.

CSS
/* ——— Problema sin subgrid ——— */
/* Las tarjetas tienen contenidos de alturas distintas
   y los elementos internos no se alinean */

/* ——— Solución con subgrid ——— */
.grid-tarjetas {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
  grid-template-rows: auto auto 1fr auto; /* imagen titulo desc btn */
}

.tarjeta {
  display: grid;
  grid-row: span 4;          /* ocupa las 4 filas del padre */
  grid-template-rows: subgrid; /* usa las pistas del padre */
  gap: 0;
}

/* Ahora .img, .titulo, .desc, .btn de TODAS las tarjetas
   están alineadas entre sí, independientemente del contenido */

.tarjeta .img    { grid-row: 1; }
.tarjeta .titulo { grid-row: 2; }
.tarjeta .desc   { grid-row: 3; }
.tarjeta .btn    { grid-row: 4; }

/* ——— Subgrid en columnas ——— */
.form-row {
  display: grid;
  grid-column: span 3;
  grid-template-columns: subgrid; /* columnas del padre */
}

/* ——— Dense placement ——— */
.grid-galeria {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-flow: dense; /* rellena huecos automáticamente */
  gap: 8px;
}

.item-grande { grid-column: span 2; grid-row: span 2; }
.item-ancho  { grid-column: span 2; }

Writing modes y Logical Properties

Las Logical Properties reemplazan las propiedades físicas (top, left, width, height) por propiedades relativas a la dirección del texto, lo que hace los layouts naturalmente compatibles con idiomas RTL (árabe, hebreo) y verticales (japonés, chino).

CSS
/* ——— Propiedades físicas vs lógicas ——— */
/* FÍSICAS (evitar en proyectos i18n) → LÓGICAS (usar) */

/* width  → inline-size   height → block-size */
.elemento {
  inline-size: 100%;         /* = width en modo LTR */
  block-size: 200px;         /* = height en modo LTR */
  min-inline-size: 200px;   /* = min-width */
  max-block-size: 400px;    /* = max-height */
}

/* margin/padding/border: inline (horizontal) / block (vertical) */
.texto {
  margin-inline: auto;         /* = margin-left + margin-right */
  margin-block: 1rem;          /* = margin-top + margin-bottom */
  padding-inline-start: 1rem; /* = padding-left en LTR */
  padding-inline-end: 1rem;   /* = padding-right en LTR */
  border-block-end: 1px solid #ddd; /* = border-bottom */
}

/* inset: shorthand para top/right/bottom/left */
.abs {
  position: absolute;
  inset: 0;                 /* = top:0 right:0 bottom:0 left:0 */
  inset: 10px 20px;         /* = top:10px right:20px bottom:10px left:20px */
  inset-inline: 0;          /* = left:0 right:0 */
  inset-block-start: 10px; /* = top:10px */
}

/* ——— writing-mode ——— */
.vertical-rl { writing-mode: vertical-rl; }  /* japonés */
.vertical-lr { writing-mode: vertical-lr; }  /* texto lateral */
.horizontal  { writing-mode: horizontal-tb; }

/* Texto girado para sidebar labels */
.sidebar-label {
  writing-mode: vertical-lr;
  text-orientation: mixed;
  transform: rotate(180deg);
}

/* ——— direction ——— */
[lang="ar"], [dir="rtl"] { direction: rtl; }

Buenas prácticas de CSS avanzado

  • Usa @layer desde el inicio en proyectos medianos y grandes. Declara el orden al principio del archivo principal: @layer reset, base, layout, components, utilities;
  • Sistema de tokens con Custom Properties: crea un set de variables para colores, fuentes, radios, sombras y espaciados antes de escribir cualquier selector.
  • Prefiere transform y opacity para animaciones. Nunca animes propiedades que provoquen reflow (width, height, top, margin) en loops.
  • Incluye siempre @media (prefers-reduced-motion: reduce) para desactivar animaciones a quienes las han deshabilitado en su SO.
  • Usa Logical Properties (margin-inline, padding-block, inset) en proyectos que necesiten soporte RTL o multilingüe.
  • Aplica content-visibility: auto en secciones largas fuera del viewport para mejorar el First Contentful Paint.
  • Para gradientes, usa OKLCH en lugar de HSL o sRGB: los gradientes son perceptualmente uniformes y evitan el "gris muerto" a la mitad.
  • Usa :focus-visible en lugar de :focus para estilos de teclado que no se activen con el ratón.
  • Verifica soporte con @supports (property: value) { } antes de usar características muy nuevas en producción.
  • Organiza el CSS en orden: variables → reset → base → layout → componentes → modificadores → utilidades → media queries. Nombra secciones con comentarios.
