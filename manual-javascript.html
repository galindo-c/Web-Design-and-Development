¿Qué es JavaScript?

JavaScript (JS) es el lenguaje de programación de la web. Es el único lenguaje que los navegadores ejecutan de forma nativa y permite añadir comportamiento dinámico a las páginas: responder a clics, validar formularios, actualizar contenido sin recargar la página, llamar a APIs externas y mucho más.

TecnologíaResponsabilidadAnalogía
HTMLEstructura y contenidoEl esqueleto del cuerpo
CSSPresentación visualLa ropa y el estilo
JavaScriptComportamiento e interacciónLos músculos y el cerebro

¿Dónde se ejecuta?

🌐 En el navegador (Frontend)

Manipula el DOM, escucha eventos, llama APIs, almacena datos en localStorage.

// Se incluye en HTML
<script src="app.js"></script>
// O inline al final del body
⚙️ En el servidor (Node.js)

Servidores web, APIs REST, scripts de automatización, acceso a bases de datos.

// Ejecutar en terminal
$ node app.js
$ npm start
Historia rápida

JavaScript fue creado en 1995 por Brendan Eich en solo 10 días. A pesar de su nombre, no tiene ninguna relación con Java. El estándar oficial se llama ECMAScript. ES6 (2015) introdujo las mejoras más importantes del lenguaje.

Bucles (Loops)

JavaScript
// for — cuando sabes cuántas veces iterar
for (let i = 0; i < 5; i++) {
  console.log(`Iteración ${i}`);
}

// while — mientras se cumpla una condición
let n = 1;
while (n <= 10) {
  console.log(n);
  n++;
}

// do...while — se ejecuta al menos una vez
let intento = 0;
do {
  console.log(`Intento ${intento}`);
  intento++;
} while (intento < 3);

// for...of — iterar valores de arrays, strings, etc.
const frutas = ["manzana", "pera", "uva"];
for (const fruta of frutas) {
  console.log(fruta);
}

// for...in — iterar las claves de un objeto
const persona = { nombre: "Ana", edad: 30 };
for (const clave in persona) {
  console.log(`${clave}: ${persona[clave]}`);
}

// break y continue
for (let i = 0; i < 10; i++) {
  if (i === 3) continue;  // salta el 3
  if (i === 7) break;     // sale del bucle en 7
  console.log(i);          // 0 1 2 4 5 6
}

Scope y Closures

Scope (ámbito)

El scope define dónde son accesibles las variables. JavaScript tiene tres niveles de scope:

SCOPE GLOBAL
let idioma = "es";
SCOPE DE FUNCIÓN
const usuario = "Ana";
// Puede acceder a: idioma, usuario
SCOPE DE BLOQUE
let resultado = 42;
// Puede acceder a: idioma, usuario, resultado
// ❌ No puede acceder a: resultado
// ❌ No puede acceder a: usuario, resultado
JavaScript
// Global scope
const global = "soy global";

function externa() {
  const enFuncion = "soy de la función";

  if (true) {
    let   enBloque = "soy del bloque";  // solo aquí
    var   conVar   = "soy de la función"; // var ignora bloques
    console.log(global);                 // ✅ "soy global"
    console.log(enFuncion);              // ✅ "soy de la función"
  }

  console.log(conVar);                 // ✅ var trasciende el bloque
  // console.log(enBloque);            // ❌ ReferenceError
}

externa();
// console.log(enFuncion);            // ❌ ReferenceError

Closures

Un closure es una función que recuerda el scope en que fue creada, incluso después de que ese scope haya terminado. Es uno de los conceptos más poderosos de JavaScript.

JavaScript
// Ejemplo 1 — Contador con closure
function crearContador() {
  let cuenta = 0;              // variable privada
  return {
    incrementar: () => ++cuenta,
    decrementar: () => --cuenta,
    valor:       () => cuenta,
  };
}

const c = crearContador();
c.incrementar();              // cuenta → 1
c.incrementar();              // cuenta → 2
c.decrementar();              // cuenta → 1
console.log(c.valor());       // 1
// "cuenta" no es accesible desde fuera: es privada

// Ejemplo 2 — Función multiplicadora
const multiplicarPor = (factor) =>
  (numero) => numero * factor;  // recuerda "factor"

const doble   = multiplicarPor(2);
const triple  = multiplicarPor(3);
console.log(doble(5));    // 10
console.log(triple(5));   // 15

Arrays

Los arrays son listas ordenadas de valores. Son uno de los tipos de dato más usados en JavaScript y cuentan con potentes métodos de transformación.

JavaScript
// Creación
const frutas  = ["manzana", "pera", "uva"];
const mixto   = [1, "hola", true, null];
const vacio   = [];
const rango   = Array.from({length: 5}, (_, i) => i + 1); // [1,2,3,4,5]

// Acceso e información
frutas[0]              // "manzana" (índice 0)
frutas.length          // 3
frutas.at(-1)          // "uva" (último elemento)
frutas.indexOf("pera") // 1
frutas.includes("uva") // true

// Modificación
frutas.push("kiwi");      // agrega al final → ["manzana","pera","uva","kiwi"]
frutas.pop();              // elimina el último → ["manzana","pera","uva"]
frutas.unshift("fresa");  // agrega al inicio
frutas.shift();            // elimina el primero
frutas.splice(1, 1);      // elimina 1 elemento desde índice 1

// Iterar
frutas.forEach((f, i) => console.log(`${i}: ${f}`));

Métodos funcionales (los más importantes)

JavaScript
const nums = [1, 2, 3, 4, 5, 6];

// .map() — transforma cada elemento → nuevo array
const dobles  = nums.map(n => n * 2);
// [2, 4, 6, 8, 10, 12]

// .filter() — filtra elementos que cumplan condición → nuevo array
const pares   = nums.filter(n => n % 2 === 0);
// [2, 4, 6]

// .reduce() — reduce a un solo valor
const total   = nums.reduce((acc, n) => acc + n, 0);
// 21

// .find() — primer elemento que cumpla condición (o undefined)
const primPar = nums.find(n => n % 2 === 0);
// 2

// .some() — ¿alguno cumple la condición?
const hayImpares = nums.some(n => n % 2 !== 0);
// true

// .every() — ¿todos cumplen la condición?
const todosPares = nums.every(n => n % 2 === 0);
// false

// .sort() — ordena (in-place!)
[3, 1, 4, 1, 5].sort((a, b) => a - b);   // ascendente

// Encadenamiento (chaining)
const resultado = nums
  .filter(n => n % 2 === 0)  // [2, 4, 6]
  .map(n => n ** 2)             // [4, 16, 36]
  .reduce((a, b) => a + b, 0); // 56

Objetos

Los objetos son colecciones de pares clave-valor. Son la estructura de datos más fundamental en JS — todo en JavaScript es un objeto (o se comporta como uno).

JavaScript
// Creación con notación literal
const persona = {
  nombre:  "Ana García",
  edad:    28,
  activa:  true,
  skills:  ["JS", "CSS", "React"],
  dirección: {
    ciudad: "México",
    país:   "MX"
  },
  // Método
  saludar() {
    return `Hola, soy ${this.nombre}`;
  }
};

// Acceso a propiedades
persona.nombre            // "Ana García" — dot notation
persona["edad"]           // 28 — bracket notation
persona.dirección.ciudad  // "México" — propiedad anidada
persona.saludar()         // "Hola, soy Ana García"

// Modificar y agregar propiedades
persona.edad = 29;
persona.email = "ana@ejemplo.com";

// Eliminar propiedad
delete persona.activa;

// Verificar existencia
"nombre" in persona       // true
persona.hasOwnProperty("nombre") // true

Métodos útiles de Object

JavaScript
const obj = { a: 1, b: 2, c: 3 };

Object.keys(obj)       // ["a", "b", "c"]
Object.values(obj)     // [1, 2, 3]
Object.entries(obj)    // [["a",1], ["b",2], ["c",3]]

// Clonar un objeto (shallow copy)
const copia  = { ...obj };                  // spread
const copia2 = Object.assign({}, obj);     // Object.assign

// Combinar objetos
const extras  = { d: 4, e: 5 };
const fusión  = { ...obj, ...extras };
// { a:1, b:2, c:3, d:4, e:5 }

// Destructuring — extraer propiedades
const { nombre, edad, ciudad = "CDMX" } = persona;
// nombre = "Ana García"
// edad   = 29
// ciudad = "CDMX" (default, no existía)

// Desestructurar con renombre
const { nombre: nombreCompleto } = persona;
// nombreCompleto = "Ana García"

// JSON — serializar y deserializar
const json    = JSON.stringify(persona);    // → string JSON
const parsed  = JSON.parse(json);           // → objeto JS

El DOM

El DOM (Document Object Model) es la representación en memoria del HTML de una página. JavaScript puede leer y modificar el DOM en tiempo real, lo que permite crear interfaces dinámicas sin recargar la página.

document
└─ <html>
├─ <head>
│ └─ <title> "Mi Página" </title>
└─ <body>
├─ <h1 id="titulo"> "Hola" </h1>
└─ <ul class="lista">
├─ <li> "Elemento 1" </li>
└─ <li> "Elemento 2" </li>
JavaScript
// ——— Seleccionar elementos ———
const titulo  = document.getElementById("titulo");
const primer  = document.querySelector(".lista li");     // primero
const todos   = document.querySelectorAll("li");          // todos (NodeList)
const lista   = document.querySelector(".lista");

// ——— Leer y modificar contenido ———
titulo.textContent   = "Nuevo título";     // texto plano (seguro)
titulo.innerHTML     = "Título <em>cursiva</em>"; // HTML (con cuidado)
titulo.innerText     = "Texto visible";    // respeta CSS

// ——— Estilos inline ———
titulo.style.color    = "#F0A500";
titulo.style.fontSize = "2rem";

// ——— Clases CSS ———
titulo.classList.add("activo");
titulo.classList.remove("activo");
titulo.classList.toggle("activo");         // alterna
titulo.classList.contains("activo");       // true/false

// ——— Atributos ———
titulo.setAttribute("data-id", "42");
titulo.getAttribute("id");                 // "titulo"
titulo.removeAttribute("data-id");

// ——— Crear y agregar elementos ———
const nuevoItem = document.createElement("li");
nuevoItem.textContent = "Nuevo elemento";
lista.appendChild(nuevoItem);              // al final
lista.prepend(nuevoItem);                  // al inicio

// ——— Eliminar elementos ———
nuevoItem.remove();                         // elimina el elemento

Eventos

Los eventos son acciones del usuario o del navegador a las que JavaScript puede reaccionar: clics, teclas, scroll, carga de la página, etc.

JavaScript
// Forma recomendada: addEventListener
const boton = document.querySelector("#mi-boton");

boton.addEventListener("click", (evento) => {
  console.log("Clic detectado");
  console.log(evento.target);   // el elemento clickeado
});

// Remover listener
const handler = () => console.log("clic");
boton.addEventListener("click", handler);
boton.removeEventListener("click", handler);

// Eventos de teclado
document.addEventListener("keydown", (e) => {
  console.log(e.key);         // tecla presionada
  if (e.key === "Enter") {  // Enter específicamente
    console.log("¡Enter presionado!");
  }
  if (e.ctrlKey && e.key === "s") {
    e.preventDefault();      // evita el comportamiento nativo
    console.log("Guardando...");
  }
});

// Evento de formulario
const form = document.querySelector("form");
form.addEventListener("submit", (e) => {
  e.preventDefault();        // evita recarga de la página
  const datos = new FormData(form);
  console.log(datos.get("email"));
});

// Event delegation — un listener para muchos hijos
const lista = document.querySelector("#mi-lista");
lista.addEventListener("click", (e) => {
  if (e.target.matches("li")) {
    console.log("Clic en:", e.target.textContent);
  }
});

ES6+ — JavaScript moderno

ES6 (ECMAScript 2015) introdujo cambios fundamentales en el lenguaje. Aquí están las características más importantes que debes dominar.

// Desestructuración de arrays
const [primero, segundo, ...resto] = [1, 2, 3, 4, 5];
// primero = 1, segundo = 2, resto = [3,4,5]

// Intercambiar variables
let a = 1, b = 2;
[a, b] = [b, a];   // a=2, b=1

// Desestructuración de objetos
const config = { host: "localhost", port: 3000, debug: true };
const { host, port = 8080, debug } = config;

// En parámetros de función
function mostrarUsuario({ nombre, edad, rol = "usuario" }) {
  return `${nombre} (${edad}) — ${rol}`;
}

// Desestructuración anidada
const { nombre, dirección: { ciudad } } = persona;
// Spread en arrays
const a = [1, 2, 3];
const b = [4, 5, 6];
const c = [...a, ...b];        // [1,2,3,4,5,6]
const copia = [...a];          // copia independiente

// Spread en objetos
const base    = { color: "azul", peso: 1 };
const nuevo   = { ...base, color: "rojo", talla: "M" };
// { color: "rojo", peso: 1, talla: "M" } — rojo sobreescribe azul

// Rest en funciones
function log(nivel, ...mensajes) {
  console.log(`[${nivel}]`, ...mensajes);
}
log("INFO", "Usuario", "conectado", "exitosamente");

// Spread para pasar array como argumentos
const nums = [3, 1, 4, 1, 5];
Math.max(...nums);                 // 5
// Template literals — backticks ` `
const nombre  = "Ana";
const edad    = 28;

// Interpolación de expresiones
const saludo = `Hola, ${nombre}. Tienes ${edad} años`;
const calc   = `2 + 2 = ${2 + 2}`;
const cond   = `Eres ${edad >= 18 ? "mayor" : "menor"} de edad`;

// Multilínea
const html = `
  <div class="tarjeta">
    <h2>${nombre}</h2>
    <p>Edad: ${edad}</p>
  </div>
`;

// Tagged templates (avanzado)
function sql(strings, ...values) {
  // sanitizar valores para SQL injection prevention

    acc + str + (values[i] ?? ""), "");
}
const query = sql`SELECT * FROM users WHERE id = ${userId}`;

// Dynamic import (lazy loading)
const { sumar } = await import('./math.js');

// En HTML: type="module"
// <script type="module" src="app.js"></script>
// Clases (ES6) — syntactic sugar sobre prototypes
class Animal {
  // Campo privado (ES2022)
  #nombre;

  constructor(nombre, especie) {
    this.#nombre  = nombre;
    this.especie = especie;
  }

  // Getter
  get nombre() { return this.#nombre; }

  // Método de instancia
  hablar() { return `${this.#nombre} hace un sonido`; }

  // Método estático
  static crear(nombre) { return new Animal(nombre, "desconocida"); }
}

// Herencia
class Perro extends Animal {
  constructor(nombre) {
    super(nombre, "Canis lupus");  // llama al constructor padre
    this.raza = "mestizo";
  }

  hablar() { return `${this.nombre} dice ¡Guau!`; }  // override
}

const rex = new Perro("Rex");
console.log(rex.hablar());     // "Rex dice ¡Guau!"
console.log(rex instanceof Perro);   // true
console.log(rex instanceof Animal);  // true

Asincronía: Callbacks, Promises y async/await

JavaScript es single-threaded: ejecuta una tarea a la vez. Las operaciones lentas (red, archivos, timers) son asíncronas: se inician y JS continúa ejecutando; cuando terminan, llaman al código registrado para manejar el resultado.

Callbacks — el origen

JavaScript
// setTimeout — ejecutar después de un tiempo
setTimeout(() => {
  console.log("Ejecutado después de 2 segundos");
}, 2000);

// setInterval — ejecutar cada N ms
const id = setInterval(() => {
  console.log("Tick");
}, 1000);
clearInterval(id);  // detener el intervalo

// "Callback hell" — el problema a evitar
obtenerUsuario(id, (usuario) => {
  obtenerPosts(usuario.id, (posts) => {
    obtenerComentarios(posts[0].id, (comentarios) => {
      // código difícil de leer y mantener
    });
  });
});

Promises — la solución

JavaScript
// Crear una Promise
const promesa = new Promise((resolve, reject) => {
  setTimeout(() => {
    const exito = true;
    if (exito) resolve({ datos: "datos recibidos" });
    else       reject(new Error("Algo salió mal"));
  }, 1000);
});

// Consumir con .then()/.catch()/.finally()
promesa
  .then(resultado => console.log(resultado.datos))
  .catch(error   => console.error(error.message))
  .finally(()    => console.log("Terminado"));

// Promise.all — esperar varias en paralelo
const [u, p] = await Promise.all([getUser(), getPosts()]);

// Promise.allSettled — espera todas aunque fallen
const resultados = await Promise.allSettled([p1(), p2(), p3()]);

// Promise.race — la primera que resuelva
const primero = await Promise.race([servidor1(), servidor2()]);

async/await — la forma moderna

JavaScript
// async/await hace el código asíncrono legible como sincrónico
async function cargarDatos(userId) {
  try {
    // await "pausa" la función hasta que la Promise resuelva
    const usuario   = await obtenerUsuario(userId);
    const posts     = await obtenerPosts(usuario.id);
    const comentarios = await obtenerComentarios(posts[0].id);

    return { usuario, posts, comentarios };

  } catch (error) {
    console.error("Error:", error.message);
    throw error;   // propagar el error si es necesario
  } finally {
    console.log("Carga finalizada");
  }
}

// Una función async SIEMPRE retorna una Promise
cargarDatos(1).then(datos => console.log(datos));

// Top-level await (en módulos ES)
const datos = await cargarDatos(1);

Fetch y consumo de APIs

La Fetch API permite hacer peticiones HTTP desde JavaScript. Es la forma estándar de comunicarse con APIs REST para obtener, crear, actualizar o eliminar datos.

JavaScript
// GET — obtener datos
async function getUsuario(id) {
  const respuesta = await fetch(`https://api.ejemplo.com/users/${id}`);

  if (!respuesta.ok) {  // ok = true si status 200-299
    throw new Error(`HTTP error: ${respuesta.status}`);
  }

  const datos = await respuesta.json();  // parsear JSON
  return datos;
}

// POST — crear datos
async function crearUsuario(usuario) {
  const resp = await fetch("https://api.ejemplo.com/users", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": `Bearer ${token}`
    },
    body: JSON.stringify(usuario)
  });
  return resp.json();
}

// PUT — actualizar datos
async function actualizarUsuario(id, cambios) {
  const resp = await fetch(`https://api.ejemplo.com/users/${id}`, {
    method: "PUT",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(cambios)
  });
  return resp.json();
}

// DELETE
async function eliminarUsuario(id) {
  await fetch(`https://api.ejemplo.com/users/${id}`, {
    method: "DELETE"
  });
}

Manejo de errores y buenas prácticas

JavaScript
// Wrapper genérico con manejo de errores
async function apiFetch(url, opciones = {}) {
  try {
    const resp = await fetch(url, opciones);

    if (!resp.ok) {
      throw new Error(`${resp.status}: ${resp.statusText}`);
    }

    // Detectar tipo de contenido
    const tipo = resp.headers.get("content-type");
    if (tipo?.includes("application/json")) {
      return await resp.json();
    }
    return await resp.text();

  } catch (err) {
    console.error("Fetch error:", err);
    throw err;
  }
}

// AbortController — cancelar peticiones
const ctrl    = new AbortController();
const timeout = setTimeout(() => ctrl.abort(), 5000);

const datos = await fetch(url, { signal: ctrl.signal });
clearTimeout(timeout);

Buenas prácticas

✓ Correcto
// const por defecto
const MAX = 100;
let   i   = 0;

// Nombres descriptivos
const calcularDescuento =
  (precio, porcentaje) =>
    precio * (1 - porcentaje / 100);

// Igualdad estricta
if (valor === null) { }

// async/await limpio
const datos = await fetchData();
✗ Evitar
// var causa bugs de scope
var x = 1;

// Nombres sin significado
const f = (a, b) => a * (1 - b/100);

// == coerciona tipos
if (valor == null) { }

// Callbacks anidados
getData((r) => {
  parse(r, (d) => { ... });
});
  • Usa const por defecto y let solo cuando necesites reasignar. Nunca var en código nuevo.
  • Usa siempre === y !== en lugar de == y != para evitar coerciones inesperadas.
  • Prefiere async/await sobre callbacks anidados o cadenas .then().then() largas. El código es más legible.
  • Pon siempre un try/catch alrededor de llamadas await para manejar errores de red.
  • Usa nombres descriptivos: calcularDescuento > calc > f. El código se lee más que se escribe.
  • Evita mutar arrays y objetos directamente. Usa spread, map, filter para crear copias.
  • Usa event delegation en lugar de añadir listeners individuales a cada elemento de una lista.
  • Aplica e.preventDefault() en formularios para evitar recargas de página al hacer submit.
  • Usa textContent en lugar de innerHTML cuando el contenido es texto plano — evita ataques XSS.
  • Organiza tu código en módulos con import/export desde el inicio del proyecto, aunque sea pequeño.
